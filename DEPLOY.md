# Как выложить Petuh Party в интернет бесплатно

Инструкция для тех, кто делает это первый раз. Терминал, программирование и установка программ не нужны — всё делается в браузере. Займёт 15–20 минут.

Понадобится два бесплатных аккаунта:

- **GitHub** — место, где хранится код сайта.
- **Render** — хостинг, который берёт код с GitHub и запускает сайт. Бесплатный тариф не требует банковской карты.

Схема простая: вы кладёте папку проекта на GitHub → Render забирает её, собирает и даёт вам адрес вида `https://petuh-party.onrender.com`. Этот адрес вы и отправляете друзьям.

---

## Шаг 1. Распакуйте архив

Распакуйте `petuh-party.zip`. Внутри будет папка `petuh-party` с файлами `package.json`, `render.yaml`, папками `src`, `server`, `public` и другими.

## Шаг 2. Заведите аккаунт на GitHub

1. Откройте [github.com/signup](https://github.com/signup).
2. Введите почту, придумайте пароль и имя пользователя, подтвердите почту кодом из письма.

Если аккаунт уже есть — просто войдите.

## Шаг 3. Создайте репозиторий и загрузите файлы

Репозиторий — это папка проекта на GitHub.

1. Откройте [github.com/new](https://github.com/new).
2. В поле **Repository name** напишите `petuh-party`.
3. Оставьте **Public** (публичный) — так проще подключить к Render. Код будет виден всем, но паролей и секретов в нём нет.
4. Галочки ниже не ставьте. Нажмите **Create repository**.
5. На открывшейся странице найдите ссылку **uploading an existing file** и нажмите её.
6. Откройте распакованную папку `petuh-party` на компьютере, выделите **всё её содержимое** (Ctrl+A) и перетащите в окно браузера. Важно: перетаскивайте файлы и папки *изнутри*, а не саму папку `petuh-party`.
7. Дождитесь, пока загрузятся все файлы, и нажмите зелёную кнопку **Commit changes** внизу.

Проверьте: на главной странице репозитория сразу должны быть видны `package.json`, `render.yaml` и папки `src`, `server`, `public`. Если вместо них одна папка `petuh-party` — вы загрузили саму папку. Удалите репозиторий (Settings → в самом низу Delete this repository) и повторите шаг 3.

## Шаг 4. Заведите аккаунт на Render

1. Откройте [dashboard.render.com/register](https://dashboard.render.com/register).
2. Нажмите **GitHub** — вход через тот же аккаунт. Render попросит доступ к GitHub, разрешите.
3. Если спросят, для чего вы используете Render, выберите любой вариант (например, *Personal project*).

## Шаг 5. Создайте сайт на Render

1. В панели Render нажмите **+ New** (сверху справа) → **Web Service**.
2. Выберите **GitHub** и найдите в списке репозиторий `petuh-party`. Если его нет, нажмите **Configure GitHub** / **Configure account** и дайте Render доступ к этому репозиторию.
3. Нажмите на репозиторий. Откроется форма. Заполните так:

| Поле | Что написать |
|---|---|
| **Name** | `petuh-party` (из этого получится адрес сайта; если имя занято, Render добавит к нему символы) |
| **Language** | `Node` |
| **Branch** | `main` |
| **Region** | `Frankfurt (EU Central)` — ближе всего к России |
| **Root Directory** | оставить пустым |
| **Build Command** | `npm install && npm run build` |
| **Start Command** | `npm start` |
| **Instance Type** | **Free** |

4. Нажмите **Deploy Web Service** внизу.

Начнётся сборка — внизу побегут строчки лога. Через 2–4 минуты появится зелёная надпись **Live**, а в логе — строка `[petuh-party] http://localhost:10000`. Значит, всё работает.

## Шаг 6. Откройте сайт

Адрес сайта написан сверху, под названием сервиса, например `https://petuh-party.onrender.com`. Откройте его, создайте комнату и отправьте ссылку на комнату друзьям — кнопка с кодом комнаты в шапке копирует приглашение.

Готово.

---

## Как обновить сайт

Когда поменяете файлы проекта:

1. Откройте репозиторий на GitHub → **Add file** → **Upload files**.
2. Перетащите изменённые файлы и папки (с той же структурой) → **Commit changes**.

Render сам заметит изменения и пересоберёт сайт за пару минут. Следить за этим можно во вкладке **Events** на Render.

---

## Что важно знать о бесплатном тарифе

- **Засыпание.** Если 15 минут на сайте никого нет, Render его «усыпляет». Первый, кто откроет сайт после этого, подождёт около минуты, пока он проснётся. Пока в комнате кто-то есть, сайт не засыпает.
- **Комнаты не сохраняются навсегда.** Комнаты и чат живут в памяти сервера. После засыпания или обновления сайта история чата пропадёт, а комнату можно просто создать заново (тот же код снова работает).
- **Лимит часов.** Бесплатно даётся 750 часов работы в месяц — этого хватает, чтобы один сайт работал круглосуточно.

**Не хотите ждать минуту при первом заходе?** Можно «будить» сайт заранее: зарегистрируйтесь на [cron-job.org](https://cron-job.org), создайте задание (**Create cronjob**) с адресом `https://ВАШ-АДРЕС.onrender.com/health` и интервалом **каждые 10 минут**. Тогда сайт не будет засыпать. Месячного лимита хватает впритык на один такой сайт.

## Если что-то не работает

**Сборка на Render упала (красная надпись Failed).** Откройте лог и пролистайте к концу. Чаще всего причина — файлы загружены на GitHub внутри лишней папки (см. проверку в шаге 3) или в поле Build Command опечатка.

**Видео из VK пишет, что недоступно.** Автор ролика запретил встраивание на другие сайты, или видео закрыто настройками приватности. Такое видео не покажет ни один сайт, кроме самого VK. Попробуйте другой ролик. Если ролик ваш или доступен по ссылке, вставьте код для встраивания: в VK откройте у видео меню «Поделиться», найдите код для вставки на сайт и скопируйте строку `<iframe ...>` целиком — сайт её поймёт.

**«Браузер не дал запустить видео».** Браузеры запрещают автозапуск видео со звуком, пока вы не нажали что-нибудь на странице. Нажмите кнопку **Запустить** под видео или ▶ в самом плеере — дальше синхронизация пойдёт сама.

**Реклама в VK.** Перед некоторыми роликами VK показывает рекламу. У каждого она своя, поэтому сайт ждёт, пока она закончится, и потом догоняет остальных.

**YouTube не грузится.** В России YouTube работает с перебоями — это ограничение со стороны провайдеров, сайт тут ни при чём. VK Видео и Rutube работают без этого.

**Кто-то отстаёт.** Сайт сам подтягивает отстающих каждые полсекунды. Если видео подвисло, нажмите кнопку синхронизации (круглая стрелка справа под видео). Во вкладке **Зрители** видно, у кого какое время и насколько он расходится с комнатой.

## Для любопытных: запуск на своём компьютере

Это необязательно. Понадобится [Node.js](https://nodejs.org) версии 20 или новее. В папке проекта выполните:

```
npm install
npm run dev
```

и откройте `http://localhost:3000`.

Проект можно запустить и на любом другом хостинге, где есть Node.js 20+ (команды сборки и запуска те же, что в шаге 5) или Docker (в проекте есть `Dockerfile`).
