# Petuh Party

Совместный просмотр видео с друзьями: одна ссылка — и у всех видео идёт на одной секунде. Пауза, перемотка и запуск общие, рядом чат с реакциями, ответами и картинками.

**Поддерживается:** VK Видео (включая клипы и код вставки `<iframe>`), YouTube, Rutube, прямые ссылки на `.mp4` / `.webm` и потоки `.m3u8`.

**Ещё умеет:**

- **Реакции на экран.** Эмодзи над полем сообщения вылетают поверх видео у всех зрителей, с именем отправителя. Набор (до 10 штук) каждый настраивает под себя. Видны и в полноэкранном режиме сайта (клавиша F).
- **Кто на какой секунде.** Под видео — полоса со всеми зрителями: время у каждого и насколько он отстаёт или опережает комнату.
- **Свои стикеры** — больше 60: петух Петя с эмоциями, кино, фразы про совместный просмотр («Лагает», «Догоняю», «Ты где?»), цыплёнок Цыпа и классика. Поиск по словам, разделы, недавние. Рисуются скриптом `tools/stickers.py`.
- **Реакции на сообщения.** Двойное нажатие или клик — 😭. На телефоне удержание открывает меню: реакции, ответ, копирование текста.
- **Картинки в чате**, ответы цитатой, звук новых сообщений.
- **Горячие клавиши:** пробел — пауза, ← → — 10 секунд, F — весь экран, M — звук, C — чат, ? — подсказка.
- **Установка как приложение** на телефон и компьютер.
- **Демо-фильмы** на главной, чтобы проверить синхронизацию, когда своей ссылки нет.

## Как устроена синхронизация

- **Сервер хранит единственное верное состояние:** играет/пауза, позиция и серверное время этой позиции. Любой участник может нажать паузу или перемотать — сервер принимает действие и рассылает новое состояние всем.
- **Клиент подстраивается сам.** Каждые полсекунды он сравнивает свой плеер с «ожидаемой» позицией (позиция + сколько прошло времени по часам сервера) и поправляет: запускает, ставит на паузу или перематывает. Для файлов отставание выравнивается мягко — скоростью воспроизведения, без рывков.
- **Часы сверяются** серией пингов, берётся замер с наименьшей задержкой — поэтому зрители на разных устройствах расходятся на сотые доли секунды.
- **Свои действия отличаются от чужих.** Событие плеера считается действием человека, только если оно расходится с состоянием комнаты и не вызвано командой самого сайта. Так нет эха и «перетягивания каната».
- **VK** управляется через официальный JS API (`vk.com/js/api/videoplayer.js`). У VK нет события перемотки, поэтому перемотку ползунком внутри плеера сайт ловит по скачку времени. Для встраивания сервер получает у VK `hash` через публичный `video.getOembed` — без него многие ролики не открываются на сторонних сайтах. Реклама VK не ломает синхронизацию: сайт ждёт её окончания и догоняет.

## Структура

```
server/       сервер: HTTP + WebSocket (ws), комнаты, VK hash и названия роликов
shared/       общий код: типы сообщений, разбор ссылок, список стикеров
src/          клиент на React
  player/     адаптеры плееров (vk, youtube, rutube, html5) и движок синхронизации sync.ts
  components/ интерфейс
public/       иконки, шрифты (Onest, Unbounded — OFL), стикеры, sw.js для установки приложения
tools/        stickers.py — генератор стикеров (нужен Python и fontTools, для сборки сайта не нужен)
build.mjs     сборка через esbuild
```

## Команды

```
npm install      установить зависимости
npm run dev      разработка: http://localhost:3000, пересборка при изменениях
npm run build    сборка в dist/
npm start        запуск собранного сервера (порт из переменной PORT, по умолчанию 3000)
```

Требуется Node.js 20+. Состояние комнат хранится в памяти: один процесс сервера, без базы данных.
